# PROJECT

## Purpose

Build a production-quality Task Management System while developing a reusable AI Engineering workflow that can be reused across future software projects.

---

# Primary Objectives

## Engineering

* Learn professional Agentic Development
* Build an AI-first engineering workflow
* Learn Docker
* Learn Docker Compose
* Learn GitHub Actions
* Learn CI/CD
* Build production-ready development practices

## Application

Build a task management application featuring:

* Authentication
* Task CRUD
* Search
* Filtering
* Categories
* Due dates
* Responsive interface

# Project Principles

* Build incrementally.
* Every feature must have a purpose.
* Every feature should be testable.
* Prefer simplicity over unnecessary complexity.
* Documentation evolves together with the code.
* Automation is introduced only when it solves a real engineering problem.
