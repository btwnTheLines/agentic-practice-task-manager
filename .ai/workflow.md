For every milestone:

1. Confirm the goal.

2. Define clear acceptance criteria.

3. Produce an implementation plan.

4. Wait for approval unless instructed otherwise.

Before implementing any feature:

1. Read all relevant project documentation.

2. Summarize your understanding.

3. Produce an implementation plan.

4. Wait for approval unless instructed otherwise.

After implementation:

1. Write or update tests.

2. Run all local tests.

3. Fix any failing tests.

4. Update documentation if required.

5. Explain what changed.

6. Suggest improvements if you notice technical debt.
